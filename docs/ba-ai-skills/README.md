## 3. Plugin chính thức của Claude hữu ích cho BA

| Plugin | Skill nên dùng |
|---|---|
| product-management | `write-spec` (PRD/spec), `synthesize-research`, `sprint-planning`, `stakeholder-update`, `competitive-brief`, `brainstorm` |
| operations | `process-doc`, `process-optimization`, `change-request`, `risk-assessment` |
| data | `analyze`, `write-query` (SQL), `build-dashboard`, `create-viz` |
| design | `user-research`, `research-synthesis` |
| Connector vẽ sơ đồ | Lucid, Mermaid, Figma/FigJam: BPMN, ERD, sequence diagram, wireframe |

## 4. Gợi ý lộ trình áp dụng

1. **Thu thập yêu cầu:** skill tìm hiểu domain + Product Discovery.
2. **Đặc tả:** BA-Kit (BRD/SRS), Use Case Spec Writer, User Story INVEST + AC.
3. **Mô hình hoá:** Mermaid/Lucid cho BPMN, ERD, sequence; Figma cho wireframe.
4. **Dữ liệu:** plugin `data` cho SQL, phân tích, dashboard.
5. **Giao tiếp:** `stakeholder-update`, `process-doc`, `change-request`.
