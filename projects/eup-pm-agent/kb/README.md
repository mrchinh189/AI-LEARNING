# Kho tri thức cho đội agent: hướng dẫn thêm tài liệu

Mỗi file `.md` trong thư mục này là một tài liệu Agent Lập kế hoạch và Agent Điều phối đọc được (qua tool `kb_list`, `kb_read`).
Dòng đầu tiên của file là mô tả ngắn hiện trong `kb_list`.

Nên bổ sung dần:
- Bản text của các "Lưu đồ thao tác ERP" đã dựng (mua bán, mua bán nội bộ 3 bên, logistics kế toán, đóng hàng container, giá thành Yên Bái...).
- Thời lượng thực tế của các dự án đã xong (trung vị, P80) cho từng loại việc, để Planner bớt phải giả định.
- Quy định nội bộ liên quan tiến độ: SLA duyệt PO, MR, đề nghị thanh toán.

Các con số trong file mẫu là **giả định ban đầu**; PMO cần sửa theo thực tế EuP.
